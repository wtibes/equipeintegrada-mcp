# Publicar e atualizar o GitHub

Remote: https://github.com/wtibes/equipeintegrada-mcp

Pasta local: `c:\xampp\htdocs\equipeintegrada-mcp`

```bash
cd c:\xampp\htdocs\equipeintegrada-mcp
npm run prepare-release
git add -A
git status
```
